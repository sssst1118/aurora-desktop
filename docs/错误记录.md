# Aurora 错误记录(踩坑台账)

> **目的:犯过的错不重复犯。**
> **铁律一:任何 agent 犯错(报错、误操作、返工)后,必须在此追加一条记录并提交 git。**
> **铁律二:新 agent 开工前必读本文件,连同 [开发进度.md](./开发进度.md)。**

## 记录格式

```
| 日期 | 错误 | 根因 | 教训/防再犯 |
```

## 已知环境坑(避免重踩)

| 坑 | 说明 |
|---|---|
| git 代理 | 全局代理 127.0.0.1:7897 时开时关。**每次先试直连,不通走代理**,两条都试再报网络问题 |
| Windows 盘加密策略 | Claude 直接读 Windows 盘(C:/D:)上的截图/图片会无法解码。需要看图时,请用户重新截一张发来;自己渲染的产物写到 WSL 原生盘再读回 |
| PowerShell 管道喂 WSL | 管道会加 CRLF 导致 WSL 命令整行报错;驱动 WSL 用 heredoc(LF 干净) |
| git 提交规范 | 中文 commit message;上传 GitHub 的内容不留 AI 痕迹(无 Co-Authored-By 等署名) |

## 协作纪律(多 agent 通用)

- 状态变了(环境、配置、文件)立即更新 [开发进度.md](./开发进度.md) 并提交;
- 犯了上面没有的新错 → 按格式追加本文件;
- 引用本项目之外的经验时,以本机实测为准,不要照搬记忆。
