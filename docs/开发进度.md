## 多 agent 协作约定

- 每个任务同一时刻只允许一个 agent 领取:领取时把状态改为 🔵 + 填负责人;
- 任务完成:状态 ✅ + 更新时间 + 一句话完成说明;
- 遇到阻塞:状态 🟥 + 备注写明阻塞原因,不要默默跳过;
- 跨 agent 依赖(如 1.1 是 1.2~1.5 的前置)标注在备注;
- 修改本文件后必须 git commit(中文 commit message),推不推远端视情况;
- 找不到参考实现时,先看 [docs/开发文档.md](./开发文档.md) 第 11 节参考项目清单;
- **犯错必记**:踩了坑(报错/返工/误操作)必须追加到 [docs/错误记录.md](./错误记录.md),铁律,防止其他 agent 重复踩坑。
