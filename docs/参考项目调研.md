# 参考项目调研笔记(Task 1 Step 1)

## 可借鉴点

### 1. 窗口呼出的"置顶闪切"强制提升法(必借鉴,Task 2 用)
- 位置:`src-tauri/src/window/mod.rs` 的 `show_and_focus_settings_window()`
- 背景:Windows 前台锁限制下 `set_focus`(SetForegroundWindow)可能失败;窗口已打开但被遮挡时,`show()` 不提升 Z 序
- 做法:`show()` 之后先 `set_always_on_top(true)` 再 `set_always_on_top(false)`,利用 SetWindowPos(HWND_TOPMOST) 强制把窗口提到前台,再取消置顶使其保持在普通窗口最上层
- 对 Aurora:Task 2 热键呼出 search 窗口时,先 `unminimize()` + `show()` + 置顶闪切 + `set_focus()` 的顺序可以直接采用

### 2. .lnk 解析用 IShellLinkW,不止当字符串
- 位置:`crates/platform-windows/src/lnk_resolver.rs`(核心逻辑在 platform-windows crate 内)
- 做法:对 .lnk 用 COM 的 IShellLinkW 解析真实目标路径与命令行参数,而不仅是拿文件路径字符串
- 对 Aurora:Task 3 的 `AppEntry` 目前只存 lnk 路径、打开时交给 `ShellExecuteW` 即可,无需先解析目标;但若要支持"读取 lnk 内嵌参数/图标",就要走 IShellLinkW。MVP 阶段可留待 Phase2

### 3. 打开方式:ShellExecuteW 优先,失败回退 Explorer
- 位置:`crates/platform-windows/src/shell.rs`(`shell_execute_open` / `shell_open_file`)
- 做法:`ShellExecuteW(path)` 以系统默认方式打开(lnk/exe/目录通吃);先尝试 `explorer` 打开(用于目录),失败再回退 `ShellExecuteW`,双保险
- 对 Aurora:Task 3 `open_item` 用 opener crate 或 windows-sys 的 ShellExecuteW,与它的思路一致;验证时注意异常路径有回退

### 4. 搜索前端:输入框 autofocus + store 集中查询 + 外部恢复焦点
- 位置:`src-ui/components/search/SearchBar.vue`、`src-ui/stores/search-store.ts`
- 做法:搜索输入框 `autofocus=true`;查询状态/结果放 Pinia store 统一管理(而非组件内散落);`focusInput()` 方法暴露给外部,窗口每次显示后调用恢复焦点
- 对 Aurora:Task 5 的 SearchBar 同样用 Pinia store(search-store)承载查询与选中项,窗口显示时统一恢复焦点,避免组件间回调混乱

### 5. 前端入口:挂载前先异步加载后端配置,避免渲染闪烁
- 位置:`src-ui/main.ts` 的 `init()`
- 做法:`createApp` 建好后不立即 mount,先 `await` 后端配置(主题/语言),`setLocale` 完成后再 `app.mount('#app')`;入口用异步 `init()` 包裹并 `.catch` 兜底
- 对 Aurora:Task 5 的 search 窗口挂载前可先 `await useConfigStore().load()` 再 mount;异步入口 + catch 的骨架可直接采用

### 6. 托盘与热键写法与计划一致(方向确认)
- 位置:`src-tauri/src/tray/mod.rs`
- `TrayIconBuilder::new()` + `.show_menu_on_left_click(false)` + `.on_menu_event(...)` 与计划 Task 2 的写法一致;热键注册也是插件 + `on_shortcut` 回调模式,确认 Aurora 计划方向无误

## 明确不借鉴的

- ZeroLaunch 已进入**大规模插件系统重构**(AI 语义搜索等暂不可用),架构远超 Aurora Phase1 需要;其自研拼音/模糊匹配算法对 MVP(大小写不敏感子串匹配即可)过于复杂,不引入
- 多语言 i18n、WebDAV 同步、游戏模式等特性,Phase1 不做
