## 修复记录(2026-08-13 晚)

### P1 双根因(CDP 实测定位,先测后修)

**复现条件**:dev 模式必现、release 不复现;点击确实落盘(config.json 变化)但界面不切换。

**根因 ① WallpaperPanel.vue TDZ(渲染中断)**:
- `onMounted` 里 `const stopSync = watch(..., { immediate: true })`,immediate 回调在 watch 返回前**同步执行**,回调体内调用 `stopSync()` 时 const 尚在暂时性死区 → `ReferenceError: Cannot access 'stopSync' before initialization`,中断该次渲染 flush(CDP Runtime 捕获到 Vue warn)
- dev 下打开设置面板时 cfg 已加载 → 回调走到底必崩;release 下首次引导时面板早开、cfg 未就绪 → 回调 early-return 后 watch 完成初始化,不崩——精确解释"只在 dev 验收复现"
- 修复:改 `let stop = null; stop = watch(...)`,回调内 `stop?.()` 可选调用

**根因 ② store.load 旧快照覆盖竞态**:
- 设置面板激活时 onActivated 发起 config_load(整对象替换),用户紧接着点击,晚到的旧快照整体覆盖新值 → "配置落盘了但界面回跳旧状态"
- 修复(stores/config.ts):loadId 单调序号(只接受最新 load)+ lastSaveId(save **发起时**即标记,本地修改优先于任何更早发起的 load 快照);saveSafe 失败回滚走 load(force) 无条件覆盖

**顺手升级选中态视觉**:选中=蓝底白字+同色系投影+按下缩放,未选中=字段底+hover 提亮,对比度拉满(此前蓝底深字+5% 透明底,感知弱)。
