### P1 按钮选中态颜色不切换(真实 bug)

- 现象:① AI 服务商 deepseek/ollama 切换"点击不了/颜色没切换";② 主题浅色/深色/跟随系统"功能有变化但按钮本身颜色没变"
- 代码位置:Settings.vue 962/970(provider)、1423/1431/1439(theme),选中态 `bg-[var(--aurora-accent)]`,未选中 `bg-[var(--aurora-field)]`
- 证据:config.json 里 ai_provider=ollama、theme_mode=light 说明**点击确实生效并落盘**,是纯视觉问题
- 初步嫌疑(待下个对话实测确认):
  1. theme.ts apply_theme 用 `document.documentElement.style.setProperty("--aurora-accent", ...)`,需验证 CSSOM setProperty 是否真生效(CSP `style-src 'unsafe-inline'` 理论上不拦 CSSOM,但需实测)
  2. Tailwind 3.4 对 `bg-[var(--aurora-accent)]` 类名生成验证(同类 var 任意值类此前有"透明度修饰符失效"前科)
  3. Vue 响应式:store.cfg 赋值链路(pinia state `cfg: null` → load 后替换对象,模板三元 class 依赖 store.cfg 属性,理论响应式正常,需实测)
  4. 深浅主题切换后 --aurora-accent/--aurora-field 令牌值在 :root/.dark 下是否定义了正确值(global.css 11/31 行已有,需核对 :root.dark 选择器写法与 Tailwind darkMode 配置)
- 验证方法:CDP 实测(启动时 WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222,curl /json/list 拿 ws,查按钮 computed style 与 :root 变量值)——**先测后修,别猜**
