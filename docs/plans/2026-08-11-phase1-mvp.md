# Phase1 MVP 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: 用 superpowers:subagent-driven-development(推荐)或 superpowers:executing-plans 逐任务执行。步骤用 checkbox(`- [ ]`)跟踪。

**Goal:** 搭建 Aurora 桌面应用的 Phase1 MVP:一个能当"高级启动器"用的 Tauri2 应用——全局热键呼出搜索、索引并打开开始菜单应用、常驻顶部灵动岛(时间+CPU/内存)、配置持久化、系统托盘。

**Architecture:** 单进程。Rust 后端(indexer/commands/config/托盘/热键)负责系统调用;两个 WebView 窗口(island 常驻 800×48 置顶不抢焦点、search 620×420 热键唤起)共享后端状态;前端 Vue3 只渲染交互。

**Tech Stack:** Tauri 2.x、Rust(serde/serde_json/windows-sys)、Vue3 + TypeScript + Vite、TailwindCSS v3、Pinia、pnpm、tauri-plugin-global-shortcut。

**参考项目(必读,避免首次问题):** [ZeroLaunch-rs](https://github.com/ZeroLaunch-rs)(Tauri+Rust+Vue 极速启动器,技术栈完全一致:看它的 lnk 索引、搜索匹配、窗口显隐实现思路)、[TieZ](https://github.com/)(Tauri2 剪贴板管理器,看多窗口/托盘写法)、Seelen-UI(看灵动岛/Dock 视觉)。**借鉴思路,不抄代码**。

## Global Constraints

- 仅支持 Windows 10/11(最低 Win10 21H2);只在本机(Windows 11)开发验证
- 空闲内存目标 <120MB(Phase1 只记录基线,不设硬门槛)
- 索引只扫开始菜单目录,禁止全盘扫描
- 灵动岛窗口 `focus: false`,不得抢焦点
- 普通用户权限运行,不做管理员操作
- 前端不直接接触系统 API,全部走 Tauri invoke
- git commit 信息中文;上传 GitHub 的内容不留 AI 痕迹
- 推送必须带代理:`git -c http.proxy=http://127.0.0.1:7897 push origin main`(直连不通)
- 每任务完成:更新 docs/开发进度.md 任务状态 + 提交;踩坑追加 docs/错误记录.md

```rust
    menu::{Menu, MenuItem},

pub fn setup_tray(app: &AppHandle) -> tauri::Result<()> {
    let show_item = MenuItem::with_id(app, "show_all", "显示全部窗口", true, None::<&str>)?;
    let hide_item = MenuItem::with_id(app, "hide_all", "隐藏全部窗口", true, None::<&str>)?;
    let quit_item = MenuItem::with_id(app, "quit", "退出", true, None::<&str>)?;
    let menu = Menu::with_items(app, &[&show_item, &hide_item, &quit_item])?;

    TrayIconBuilder::new()
        .icon(app.default_window_icon().expect("no icon").clone())
        .menu(&menu)
        .show_menu_on_left_click(false)
        .on_menu_event(|app, event| match event.id.as_ref() {
            "show_all" => crate::win_utils::show_all(app),
            "hide_all" => crate::win_utils::hide_all(app),
            "quit" => app.exit(0),
            _ => {}
        })
        .build(app)?;
    Ok(())
}
```

```rust
use std::fs;
use std::path::PathBuf;

#[derive(Clone, Debug, PartialEq)]
pub struct AppEntry {
    pub name: String,
    pub path: String,
}

pub struct AppIndex {
    entries: Vec<AppEntry>,
}

impl AppIndex {
    pub fn from_dir(dir: &PathBuf) -> AppIndex {
        let mut entries = Vec::new();
        collect_lnks(dir, &mut entries);
        entries.sort_by(|a, b| a.name.to_lowercase().cmp(&b.name.to_lowercase()));
        AppIndex { entries }
    }

    pub fn search(&self, query: &str) -> Vec<AppEntry> {
        if query.trim().is_empty() {
            return Vec::new();
        }
        let q = query.to_lowercase();
        self.entries
            .iter()
            .filter(|e| e.name.to_lowercase().contains(&q))
            .take(20)
            .cloned()
            .collect()
    }
}

fn collect_lnks(dir: &PathBuf, out: &mut Vec<AppEntry>) {
    if !dir.exists() {
        return;
    }
    for entry in fs::read_dir(dir).expect("read dir") {
        let entry = entry.expect("dir entry");
        let path = entry.path();
        if path.is_dir() {
            collect_lnks(&path, out);
        } else if path.extension().map(|e| e == "lnk").unwrap_or(false) {
            let name = path
                .file_stem()
                .map(|s| s.to_string_lossy().to_string())
                .unwrap_or_default();
            out.push(AppEntry {
                name,
                path: path.to_string_lossy().to_string(),
            });
        }
    }
}
```

```rust
pub mod app_index;

use std::path::PathBuf;

pub fn default_start_menu_dirs() -> Vec<PathBuf> {
    let mut dirs = Vec::new();
    if let Ok(p) = std::env::var("APPDATA") {
        dirs.push(PathBuf::from(p).join("Microsoft/Windows/Start Menu/Programs"));
    }
    let program_data = PathBuf::from("C:/ProgramData");
    dirs.push(program_data.join("Microsoft/Windows/Start Menu/Programs"));
    dirs
}

pub fn build_index() -> app_index::AppIndex {
    let mut entries = Vec::new();
    for d in default_start_menu_dirs() {
        let sub = app_index::AppIndex::from_dir(&d);
        entries.extend(sub.entries);
    }
    // 复用 AppIndex 内部结构:重新构造带排序的索引
    let mut combined = app_index::AppIndex::empty();
    combined.entries = entries;
    combined.sort();
    combined
}
```

```rust
#[derive(Clone, Debug)]
pub struct SysStatus {
    pub cpu: f32,
    pub mem_used_mb: u64,
    pub mem_total_mb: u64,
}

#[derive(Clone, Debug, Default)]
pub struct CpuSample {
    pub idle: u64,
    pub kernel: u64,
    pub user: u64,
}

/// 两次采样差商得到 CPU 使用率(0.0-100.0)
pub fn cpu_percent(prev: &CpuSample, cur: &CpuSample) -> f32 {
    let dt_total = (cur.kernel + cur.user).saturating_sub(prev.kernel + prev.user);
    let dt_idle = cur.idle.saturating_sub(prev.idle);
    if dt_total == 0 {
        return 0.0;
    }
    let busy = dt_total.saturating_sub(dt_idle) as f32 / dt_total as f32;
    (busy * 100.0).clamp(0.0, 100.0)
}

#[tauri::command]
pub fn sys_get_status() -> SysStatus {
    // 真实实现:GetSystemTimes 取两帧采样(kernel=idle+特权)
    // Windows 的 GetSystemTimes:kernel 时间含 idle;useful 公式:
    //   total = user + kernel; idle 单列。
    // 简化:用 windows-sys 调 GetSystemTimes,两次调用间隔 100ms 取差。
    // 若 windows-sys 接入复杂,Phase1 允许退化为:读系统性能计数器或直接返回 0(注释说明)
    // 内存:GlobalMemoryStatusEx。
    sample_sys_status()
}

fn sample_sys_status() -> SysStatus {
    // TODO-REAL: 填充真实 Win32 调用,见 Step 3
```

```rust
fn sample_sys_status() -> SysStatus {
    use windows_sys::Win32::System::SystemInformation::{
        GetSystemTimes, GlobalMemoryStatusEx, FILETIME, MEMORYSTATUSEX,
    };
    unsafe {
        let mut idle1: FILETIME = std::mem::zeroed();
        let mut kernel1: FILETIME = std::mem::zeroed();
        let mut user1: FILETIME = std::mem::zeroed();
        GetSystemTimes(&mut idle1, &mut kernel1, &mut user1);
        std::thread::sleep(Duration::from_millis(120));
        let mut idle2: FILETIME = std::mem::zeroed();
        let mut kernel2: FILETIME = std::mem::zeroed();
        let mut user2: FILETIME = std::mem::zeroed();
        GetSystemTimes(&mut idle2, &mut kernel2, &mut user2);

        fn ft(t: &FILETIME) -> u64 {
            ((t.dwHighDateTime as u64) << 32) | t.dwLowDateTime as u64
        }
        let prev = CpuSample { idle: ft(&idle1), kernel: ft(&kernel1), user: ft(&user1) };
        let cur = CpuSample { idle: ft(&idle2), kernel: ft(&kernel2), user: ft(&user2) };
        let cpu = cpu_percent(&prev, &cur);

        let mut ms: MEMORYSTATUSEX = std::mem::zeroed();
        ms.dwLength = std::mem::size_of::<MEMORYSTATUSEX>() as u32;
        GlobalMemoryStatusEx(&mut ms);
        SysStatus {
            cpu,
            mem_used_mb: (ms.dwTotalPhys - ms.dwAvailPhys) / (1024 * 1024),
            mem_total_mb: ms.dwTotalPhys / (1024 * 1024),
        }
    }
}
```

```ts
import { invoke } from "@tauri-apps/api/core";

export function useTauriInvoke<T>(cmd: string) {
  const call = async (args?: Record<string, unknown>): Promise<T> => {
    try {
      return (await invoke<T>(cmd, args)) as T;
    } catch (e) {
      console.error(`invoke ${cmd} failed:`, e);
      throw e;
    }
  };
  return { call };
}
```

- [ ] **Step 2: SearchBar.vue 完整实现**

`src/components/core/SearchBar.vue`(要点:150ms 防抖、↑↓ 选择、回车打开、Esc 隐藏、空态):

```vue
<script setup lang="ts">
import { ref, nextTick } from "vue";
import { invoke } from "@tauri-apps/api/core";
import { getCurrentWindow } from "@tauri-apps/api/window";

interface AppEntry {
  name: string;
  path: string;
}

const query = ref("");
const results = ref<AppEntry[]>([]);
const selected = ref(0);
const inputEl = ref<HTMLInputElement | null>(null);
let debounceTimer: number | undefined;

const win = getCurrentWindow();

async function doSearch() {
  const q = query.value.trim();
  if (!q) {
    results.value = [];
    return;
  }
  try {
    results.value = (await invoke<AppEntry[]>("search_apps", { query: q })) ?? [];
    selected.value = 0;
  } catch (e) {
    results.value = [];
    console.error(e);
  }
}

function onInput() {
  if (debounceTimer) window.clearTimeout(debounceTimer);
  debounceTimer = window.setTimeout(doSearch, 150);
}

function selectNext() {
  if (results.value.length === 0) return;
  selected.value = (selected.value + 1) % results.value.length;
}

function selectPrev() {
  if (results.value.length === 0) return;
  selected.value = (selected.value - 1 + results.value.length) % results.value.length;
}

async function openSelected() {
  const item = results.value[selected.value];
  if (!item) return;
  await invoke("open_item", { path: item.path });
  await win.hide();
}

function onKeydown(e: KeyboardEvent) {
  if (e.key === "ArrowDown") {
    e.preventDefault();
    selectNext();
  } else if (e.key === "ArrowUp") {
    e.preventDefault();
    selectPrev();
  } else if (e.key === "Enter") {
    e.preventDefault();
    openSelected();
  } else if (e.key === "Escape") {
    win.hide();
  }
}

async function onShown() {
  query.value = "";
  results.value = [];
  await nextTick();
  inputEl.value?.focus();
}

win.onFocusChanged(({ payload: focused }) => {
  if (focused) onShown();
});
</script>

<template>
  <div class="h-full w-full flex flex-col bg-black/70 backdrop-blur-xl rounded-xl overflow-hidden text-white">
    <div class="flex items-center gap-2 px-4 py-3 border-b border-white/10">
      <span>🔍</span>
      <input
        ref="inputEl"
        v-model="query"
        class="flex-1 bg-transparent outline-none text-sm placeholder-white/40"
        placeholder="搜索应用…"
        @input="onInput"
        @keydown="onKeydown"
      />
    </div>
    <div class="flex-1 overflow-y-auto py-1">
      <div v-if="query.trim() && results.length === 0" class="px-4 py-3 text-xs text-white/40">
        无匹配结果
      </div>
      <div
        v-for="(item, i) in results"
        :key="item.path"
        class="px-4 py-2 flex items-center gap-3 text-sm cursor-pointer"
        :class="i === selected ? 'bg-white/10' : ''"
        @mouseenter="selected = i"
        @click="openSelected"
      >
        <span class="text-base">🖥️</span>
        <span>{{ item.name }}</span>
      </div>
    </div>
    <div class="px-4 py-2 text-[10px] text-white/30 border-t border-white/10">
      ↑↓ 选择 · Enter 打开 · Esc 关闭
    </div>
  </div>
</template>
```
