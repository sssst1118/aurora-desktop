# Aurora Desktop 开发文档

项目定位:Windows 平台 AI‑增强模块化桌面效率中心;基于 Tauri2 + Rust + Vue3‑TS + TailwindCSS;面向 AI / 开发者直接执行,完整可落地,包含约束、模块、接口、风险、排期。

## 1 项目总览

### 1.1 一句话定位

AI 增强模块化桌面效率中心,融合启动器、窗口管理、全局搜索、桌面收纳、灵动岛信息面板、壁纸管理、系统状态、AI 对话、Windows UI 自动化,替代 / 增强 Windows 桌面体验。

### 1.2 设计原则

- 模块化可开关:每个功能模块可在设置里开启 / 关闭,避免臃肿;
- 分层架构:Rust 后端处理系统调用、IO、搜索、AI 代理、自动化;Vue3 前端只负责渲染交互;
- 双 AI 模式:支持云端 API (DeepSeek) + 本地 Ollama 离线模型;
- Windows 优先:仅面向 Windows10/11;不兼容其他操作系统;
- 性能约束:空闲内存目标 <120MB;后台不做轮询轰炸;索引懒加载。

### 1.3 借鉴的开源理念

| 参考项目 | 吸收特性 |
|---|---|
| Seelen‑UI | 自定义 Dock、窗口平铺、高度可配置布局容器 |
| FocuSD Island | 常驻顶部灵动岛悬浮面板,媒体控制 + 系统状态 |
| GeekDesk | 一键呼出全局极速搜索,应用 / 文件检索 |
| DeskBox/Second Desk | 桌面文件抽屉收纳,文件分类管理 |
| PowerBox | AI 枢纽,对话 + 工具调用集成 |
| Lively Wallpaper | 静态 / 动态壁纸引擎 |
| TranslucentTB | 任务栏交互、系统托盘实践 |

## 2 技术栈

| 层级 | 选型 | 说明 |
|---|---|---|
| 桌面外壳 | Tauri 2.0 | Rust 后端 + Web 前端;窗口、托盘、权限管理 |
| 后端 | Rust 1.80+ | windows‑rs Windows 原生 API;文件索引;AI 代理;UI Automation 封装 |
| 前端 | Vue3 + TypeScript + Vite | Composition API;组件化拆分 |
| 样式 | TailwindCSS v3 | 无边框透明悬浮 UI、灵动岛、Dock 样式 |
| 系统插件 | tauri‑plugin‑global‑shortcut | 全局热键注册 |
| 系统插件 | tauri‑plugin‑clipboard | 剪贴板监听、历史记录 |
| 壁纸注入 | windows‑rs(自研) | WorkerW 窗口注入,动态壁纸渲染(无第三方插件) |
| AI HTTP | reqwest | Rust 后端做 API 代理,保管 API Key,不暴露前端 |
| 系统自动化 | windows‑rs(UI Automation) | 窗口控件读取、模拟点击输入;先简单键鼠模拟,再做控件识别 |
| 包管理器 | pnpm (前端) / cargo (Rust) | |

### 环境要求

- Rust MSVC 工具链
- Node.js LTS
- Windows SDK(用于 windows‑rs 编译系统 API)

## 6 模块详细需求说明

### 6.1 灵动岛 Island(常驻顶部窗口)

窗口置顶、不抢焦点;常态=时间 + CPU/内存/网络;
交互:单击展开 / 收起 Dock(括入区,拖拽 exe/lnk 添加);双击或热键呼出主面板;可拖动,位置防抖落盘记忆;
可在设置关闭,关闭后隐藏 island 窗口(非销毁;重新开启即时恢复)。

### 6.2 Dock 栏

括入灵动岛展开区(唯一 Dock 载体,不再独立成窗):拖拽 exe/lnk 进岛添加、悬停 ✕ 移除、＋ 提示、溢出「…」浮层;点击启动(脉冲反馈+岛收回);
支持显示正在运行程序标记(绿点)。

### 6.3 全局搜索 SearchBar

全局热键默认 Ctrl+Shift+Space 呼出主面板(打字即进入搜索态);Esc 层级递进:① 搜索态 → 清空输入退回小桌面;② 非搜索态且岛展开 → 岛收起(前两级面板保持打开);③ 岛已收起 → 关闭面板。岛侧广播 island-expand-state、面板侧发 island-collapse-request,纯前端事件通道,无后端命令;
输入实时过滤:应用优先,其次文件;回车打开选中项;
索引策略:启动时增量索引开始菜单;文件采用按需搜索,不做全磁盘预索引,避免 IO 爆炸。

### 6.4 FileDrawer 桌面文件抽屉

扫描桌面目录;将桌面文件收纳进抽屉 UI;
仅逻辑收纳:文件原位不动,仅 UI 分组展示;不移动文件、不清空桌面;
支持分类标签:文档、图片、安装包等。

### 6.5 剪贴板历史

后台监听剪贴板变化;持久化到本地 json;限制最大条数;
只保存文本与图片路径;不保存超大二进制;
搜索历史、点击复制回剪贴板。

### 6.6 壁纸模块

- 静态壁纸:封装SystemParametersInfoW Win32 API;
- 动态壁纸:自研 WorkerW 注入(windows‑rs 原生实现,无第三方插件);支持本地 mp4/图片素材;html 素材已禁用(安全加固);
- 风险:视频壁纸耗电,笔记本电池模式自动暂停动态渲染。

### 6.7 AI 模块

- Rust 后端做 http 代理,前端不直接访问大模型接口;
- 双模式:云端 DeepSeek / 本地 Ollama;
- Function‑call:AI 输出工具指令,后端分发调用上面 Tauri 命令;
- 示例自然语言指令:
  - "打开记事本" → open_item
  - "把这张图设为壁纸" → wallpaper_set_static
  - "查找桌面 pdf 发票" → search_files
- 高级 UI 自动化为可选高阶功能,不作为 MVP。

### 6.8 系统自动化 automation

风险最高模块,放在后期迭代

- 第一阶段:仅简单键鼠模拟输入;
- 第二阶段:windows‑rs 封装 UI Automation,遍历窗口控件;
- 限制:UWP、管理员权限程序 UI 自动化会失败,需要文档写明边界。

## 7 开发里程碑(Roadmap)

### Phase1 MVP 最小可用版本(优先交付)

- Tauri2 项目脚手架,多窗口基础;系统托盘(显示 / 隐藏全部窗口、退出)
- 全局热键注册,呼出搜索框;
- 应用搜索:索引开始菜单,打开程序;
- 基础设置存储(json 本地配置);
- 灵动岛基础 UI(仅时间 + 简单系统状态);

目标:可以当作高级启动器跑起来。

### Phase2 效率增强

- Dock 栏组件;
- FileDrawer 桌面文件抽屉(逻辑收纳模式);
- 剪贴板监听 + 历史记录持久化;
- 静态壁纸切换;
- 系统状态完整采集 CPU / 内存 / 网络。

### Phase3 AI 集成

- AI 对话面板;Rust 后端代理 DeepSeek / Ollama;
- Function‑call 基础工具调用:搜索、打开文件、设置壁纸;
- 自然语言文件搜索。

### Phase4 高级特性

- 动态壁纸(WorkerW 网页 / 视频);电池自动降载;
- 键鼠模拟自动化;
- UI‑Automation 控件操作(高阶);
- 主题系统;模块开关完善;
- MSI 打包、安装程序。

## 8 风险与约束(必须写入实现约束)

- **权限边界**:程序普通用户权限运行;无法控制管理员权限的窗口 / 软件;自动化对此类软件直接返回失败;
- **索引不要暴力扫描全盘**:文件搜索只扫描用户配置的目录集合,禁止默认遍历全部磁盘,避免磁盘卡死;
- **动态壁纸 GPU 消耗**:提供开关;笔记本检测电池状态自动禁用动态壁纸;
- **API Key 安全**:AI 密钥只保存在本地配置文件,永远不传到前端、不上传网络;
- **窗口焦点**:灵动岛面板设置 focus:false,不能抢夺输入焦点;
- **Windows 版本**:最低支持 Win10 21H2;更低版本不做兼容。

## 9 测试要点清单

- 热键重复注册、程序重启热键恢复;
- 多显示器布局下灵动岛位置;
- 空闲内存占用;长时间后台内存泄漏;
- Ollama 离线模式断网下不会崩溃;
- 托盘退出,全部后台线程正常释放;
- 设置保存重启后生效。
