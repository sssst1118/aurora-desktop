# Phase4 手动验收清单

> ⚠️ **历史快照**(Phase4 阶段编写,部分描述已过时):当前验收以 [docs/真机验收总清单.md](./真机验收总清单.md) 为准,本清单仅作 Phase4 功能点参考。
> 代码质量门已全绿(cargo test 205/205 + pnpm build)。以下为**真机人工验收项**,按模块分组,勾选通过后反馈。
> 验收统一 release:`pnpm tauri build` 后装 NSIS/MSI,或 `tauri build --no-bundle` 直接跑 exe(不要用 `pnpm tauri dev`,首次编译慢会干扰验收)。

## 4.1 动态壁纸 + 电池降载

| # | 验收项 | 步骤 | 预期 | 结果 |
|---|---|---|---|---|
| 1 | 动态壁纸注入 | 设置 → 动态壁纸选一张素材(模块默认全开,无需手动开开关) | 桌面背景被 Aurora 壁纸窗口接管(图片显示在桌面图标下层,不遮挡图标/不抢焦点) | |
| 2 | 素材展示 | 在 `图片\Pictures`(或配置的素材目录)放 2~3 张图,逐张选择 | 壁纸按所选素材展示(实现为显式 set 素材,无自动轮换;切素材即时生效) | |
| 3 | 电池降载 | 电池降载子开关开;笔记本插拔电源 | 30s 内 `wallpaper-power` 状态翻转,壁纸切换为降载形态(状态变化才切,不反复) | |
| 4 | 关闭恢复 | 关闭动态壁纸开关/退出应用 | 桌面恢复系统默认壁纸,无残留窗口 | |
| 5 | 目录外素材 | 选择 Pictures 之外的图片目录 | 后端 data URL 方案正常展示(≤50MB) | |

## 4.3 UIA 控件操作

| # | 验收项 | 步骤 | 预期 | 结果 |
|---|---|---|---|---|
| 1 | 窗口搜索 | UIA 子开关开 → 测试区窗口搜索"记事本"(留空列出全部) | 返回可见顶层窗口列表(hwnd/标题) | |
| 2 | 控件列表 | 点选窗口 → 控件列表加载 | 显示控件 id/类型/名称,可按类型过滤;多级路径(如 4.0.0)可见 | |
| 3 | 读文本 | 点选控件 → 读文本 | 显示控件 Name/Value;无值控件 → "该控件不支持 UI 自动化" | |
| 4 | 点击控件 | 点选按钮类控件 → 点击 | 控件被点击(取 BoundingRectangle 中心) | |
| 5 | 输入控件 | 点选输入框 → 输入文本 | SetFocus 成功直输;失败则点击兜底;中文安全 | |
| 6 | 边界文案 | 搜索 UWP(系统设置)→ 操作 | "UWP 应用不支持第三方控件操作" | |
| 7 | 边界文案 | 管理员权限窗口 | "目标窗口为管理员权限,当前程序无权限访问" | |
| 8 | 边界文案 | 双开关任一关 | "自动化未启用,请在设置中开启" | |
| 9 | 非法入参 | 手输非法 hwnd/控件 id | "未找到匹配的窗口/控件" / 格式错误提示 | |

> ⚠️ 已知限制:控件 id 是窗口 Z 序遍历路径(非 UIA 树序),窗口重排后需重新遍历;无窗口的 UIA 元素(DirectUI 内部控件)枚举不到。
