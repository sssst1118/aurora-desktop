# Phase6 UI 重构设计(Aurora v0.2 界面)

> 2026-08-14 定稿。设计预览稿:d:\2605\aurora-v02-preview.html(已获用户批准,落地以本设计文档为准)。
> 起源:用户真机反馈「UI 太基础、这也能叫灵动岛、体验别扭到不想用」;设计过程经多轮反馈迭代定稿:
> 搜索不是主界面 → 小桌面是主界面 → Dock 并入灵动岛 → 一岛一窗。

## 1. 目标

把 Aurora 从「6 个割裂的功能窗口」重塑为「**一岛一窗**」的一体化桌面中枢:

- **灵动岛**:屏幕顶部常驻药丸,常态=时间+系统状态;**单击展开括入 Dock**(唯一 Dock 载体);**双击/热键呼出主面板**;可拖动,位置记忆。
- **主面板**:唯一工作窗口,从岛正下方呼出,**位置跟随岛**;默认视图=**小桌面**(桌面文件);AI 助手为并列主视图;剪贴板/设置为平级视图;**搜索是打字触发的动作,不是界面**。
- **视觉**:深空玻璃+极光缘签名元素+4 套皮肤+SVG 图标体系+动效,全面替代 emoji/杂乱字号的"功能堆叠"现状。

## 2. 形态架构:一岛一窗

```
桌面
 ├─ 灵动岛 island(常驻,可拖动,药丸形态)
 │     ├─ 常态:呼吸点 + 时间 + CPU/内存/网络
 │     └─ 展开态(单击):括入 Dock 图标(真实图标/绿点/✕移除/＋添加/拖放入岛)
 │           └─ 图标点击 = 启动应用(脉冲反馈+岛收回);搜索入口 = 呼出主面板
 └─ 主面板 main(呼出式,位置绑定岛正下方)
       ├─ 默认视图:小桌面(桌面文件分类网格)
       ├─ AI 助手 / 剪贴板 / 设置(平级视图,header 图标按钮切换)
       └─ 搜索态:面板呼出后按任意键打字唤醒;结果在上,最近打开固定在下(去重)
```

### 窗口收敛

| 旧窗口 | 新形态 |
|---|---|
| island(800×48 状态条) | 药丸灵动岛(约 378×46,展开约 648×46),可拖动 |
| search(620×420) | 主面板(五视图合一),位置跟随岛,尺寸可调记忆 |
| drawer(720×520) | 并入主面板「小桌面」视图(默认视图) |
| clipboard(480×560) | 并入主面板「剪贴板」视图 |
| ai_panel(540×680) | 并入主面板「AI 助手」视图 |
| wallpaper(壁纸层) | 不变(非交互窗口) |

热键语义升级:抽屉/剪贴板/AI 热键 = 呼出主面板并定位到对应视图(不再呼出独立窗口)。

## 3. 灵动岛设计

### 3.1 三态与交互

| 动作 | 行为 |
|---|---|
| 单击岛(空白处) | 展开/收起(宽度 378→648 动画,ease-out ~280ms,括入区淡入) |
| 双击岛 | 呼出主面板(同时展开) |
| 热键 Ctrl+Shift+Space | 呼出主面板 |
| 拖动岛 | 岛整体移动(>4px 判定为拖动,不触发单击展开);位置防抖落盘配置 |
| Esc | 先收岛展开 → 再关主面板(层级递进) |

### 3.2 岛 Dock(唯一 Dock 载体,替代原主面板底部 Dock)

| 功能 | 交互 | 状态 |
|---|---|---|
| 启动应用 | 点击图标:阻断冒泡(不触发岛的单击/拖动)+ 防连点(LAUNCHING 集合短路,复用 2.1 现机制)+ 呼吸脉冲反馈 + 岛收回 | 现有后端能力复用 |
| 运行指示 | 绿点(现有 window_matches_item 轮询) | 复用 |
| 移除 | 悬停显示 ✕ 徽章,点击移除 | 复用 dock_remove 命令 |
| 添加 | 拖拽 .exe/.lnk 入展开的岛(onDragDropEvent,展开态接收;常态拖入=自动展开)+ ＋ 按钮提示 | 复用 dock_add |
| 溢出 | 图标超过可视宽度(约 10 个)时,末尾显示「…」按钮,点击弹完整列表浮层(含搜索) | 新增 |
| 预热提效 | 启动时后台预热全部 Dock 图标(现有 LNK_TARGET_CACHE + extract_icon_pixels),展开零延迟 | 复用+接线到岛 |

图标删除/添加/启动后,**主面板内不再有 Dock**,旧 Dock.vue 迁移为岛的展开内容(数据命令层不变)。

### 3.3 岛窗口技术要点

- 窗口尺寸从 800×48 改 378×46;展开态窗口 setSize 到 648×46(rAF 步进动画,~280ms,与 CSS 内容动画同步;无原生窗口动画 API)。
- 位置:默认屏幕顶部居中,可拖动;越界 clamp;防抖 600ms 落盘(island_save_geometry 新命令,或扩展 search_save_geometry 模式)。
- 展开时保持水平居中原位置(左对齐锚点不变,向右扩展)。
- focus:false / alwaysOnTop / skipTaskbar 维持现状。

## 4. 主面板设计

### 4.1 视图结构

| 视图 | header | 内容 |
|---|---|---|
| 小桌面(默认) | 标题「小桌面」 | 桌面文件分类网格(现有 DrawerPanel 内容+分类 tab) |
| AI 助手 | 标题「AI 助手」 | 现有 AIPanel 对话流 |
| 剪贴板 | 标题「剪贴板」 | 现有 ClipboardPanel 列表 |
| 设置 | 标题「设置」 | 现有 Settings(含新增皮肤区块) |
| 搜索(动作态) | 大输入框(16.5px) | 搜索结果在上(应用组/文件组)+「最近打开」固定在下(与结果重复项隐藏) |

- header 右侧 5 个 SVG 图标按钮切换视图(小桌面/搜索/剪贴板/AI/设置),当前视图高亮+accent 下划线。
- 视图切换 KeepAlive 缓存组件状态(现有 Settings KeepAlive 模式推广)。
- **打字即搜**:面板呼出后按任意可见字符(排除 IME 组合/修饰键)→ 自动切搜索态并输入;Esc 三级递进:一级=搜索态退回小桌面,二级=岛展开先收岛(面板保持),三级=关面板。
- 搜索态空输入:显示「最近打开」(应用+文件),不显示占位文案。

### 4.2 位置绑定岛

- 呼出时定位:水平居中于岛,垂直在岛下方 12px;越界 clamp 回视口内。
- 岛被拖动且面板可见时,面板实时跟随(岛 pointermove 同步重定位)。
- 面板本身仍可拖动(临时摆放),**位置不落盘**;下次呼出回到岛下方。面板尺寸记忆保留(现有 search_save_geometry 尺寸部分)。
- 呼出动画:pop-in(scale 0.96→1 + 上移,~260ms spring 曲线),视觉上从岛长出。

## 5. 视觉系统

### 5.1 令牌(皮肤 = 令牌包,4 套全进设置)

| 令牌 | 深空(默认) | 午夜 | 拂晓(浅色) | 翠野 |
|---|---|---|---|---|
| 桌面底 | #0a0f1e→#070a14 | #050507→#020203 | #e8ecf3→#dde3ec | #08120e→#050c09 |
| 玻璃面板 | rgba(15,21,40,.62) | rgba(10,10,14,.68) | rgba(255,255,255,.6) | rgba(10,24,17,.64) |
| 强调色 | #38bdf8 | #a78bfa | #4f7df9 | #34d399 |
| 极光带 | 绿#34d399→蓝#38bdf8→紫#a78bfa | 靛→紫→品红 | 同深空 | 绿→浅绿→青 |

- 保留现有 `--aurora-*` 架构,增加 `--aur-1/2/3`(极光带三色)、`--glass-hi`(玻璃高光);皮肤=body data-skin 属性切换整套令牌(与现 theme.ts 的 html.dark 机制并存,皮肤包在设置「主题」区块选择)。
- 强调色 4 色圆点选择(青/紫/绿/琥珀),保留 theme_accent 机制。
- 现有主题三态(浅色/深色/跟随系统)与皮肤关系:皮肤自带底色倾向,**皮肤替换主题三态**(拂晓=浅色皮肤,其余深色;跟随系统=浅色皮肤映射拂晓、深色皮肤用所选深色皮肤)。旧 theme_mode 字段保留兼容,皮肤字段 skin 新增,#[serde(default)]。

### 5.2 签名元素:极光缘

每个面板顶部一道 1.5px 流动渐变光带(极光三色,~9s 循环流动,柔光晕),灵动岛顶部同款短带——「Aurora 极光」名字的视觉落地,所有窗口共享的品牌视觉。

### 5.3 图标与字号

- **emoji 全部替换为内联 SVG 线性图标**(stroke 1.5-1.7):搜索/设置/剪贴板/AI/抽屉/关闭/复制/文件/文件夹/拖拽把手/删除等。设计稿内已有全套路径,直接移植。
- 字号收敛为 4 档:11(caption/辅助)/13(body)/15(标题)/17(输入);禁止任意值字号(9/10/11 档全部归并)。数字统一 tabular-nums。
- 圆角体系:面板根 16px/控件 10px/胶囊 999px,删除 4/6px 档。
- 选中态统一为一种语言:半透明底 + 左侧极光渐变竖条(+光晕);删除 Settings 内三种并存(胶囊实底/描边/色底)的不一致,胶囊选中保留实底+投影(它是"值选择"不是"列表选中",语义不同)。

### 5.4 动效规范

| 动效 | 参数 |
|---|---|
| 面板呼出 | pop-in 260ms cubic-bezier(0.22,1.28,0.5,1) |
| 结果/列表入场 | rise-in 220ms,stagger 28ms/条 |
| 岛展开 | 宽度 280ms cubic-bezier(0.22,1,0.36,1) |
| 启动脉冲 | 0.7s×2 呼吸缩放 |
| 极光缘流动 | 9s linear 循环 |
| 开关/胶囊/选中 | 150-200ms ease |
| 全部尊重 prefers-reduced-motion(降级为瞬时) | |

## 6. 数据与性能

- **Dock 图标预热**(用户要求提效):启动即后台提取全部 Dock 图标进缓存(现有 LNK_TARGET_CACHE+预热逻辑接线到岛窗口),展开/显示零延迟;主面板搜索结果图标复用同缓存。
- **最近打开**:应用(现有 recents)+ 文件(新增:open_item 打开文件时同样记入,上限 10 条,localStorage 现有方案保留)。
- 小桌面视图数据源不变(drawer 命令+watcher)。
- 内存目标 <120MB 不变:视图 KeepAlive 有界(最多缓存 4 个视图,超限 LRU 弃);采样线程/轮询逻辑无新增常驻。

## 7. 配置与迁移

- 新增字段:#[serde(default)]——`skin`(默认 "deep")、`island_x`/`island_y`(岛位置,默认 None=顶部居中,island_save_geometry 命令落盘);主面板尺寸不新增字段,沿用 search_width/search_height(尺寸可调记忆)。
- 废弃字段保留读取兼容:dock_position/dock_auto_hide(已废弃)、search_width/search_height 尺寸部分继续生效,search_x/search_y 位置部分不再消费(主面板呼出定位跟随岛)。
- 旧窗口删除后:drawer/clipboard/ai_panel 的独立窗口配置与能力声明删除;热键行为改为「呼出主面板+定位视图」。
- 配置损坏 .broken 回退机制不变。

## 8. 风险与边界

| 风险 | 对策 |
|---|---|
| 岛展开的窗口 resize 动画流畅度 | rAF 步进 setSize+CSS 内容同步动画;若卡顿降级为瞬时切换 |
| 透明窗口拖动/点击穿透 | 沿用现有 drag-region 方案;岛展开态小窗口内控件区域显式禁拖 |
| 主面板跟随岛的实时重定位抖动 | pointermove 直接 setPosition(无动画),呼出时才有动画 |
| 视图 KeepAlive 内存增长 | 上限 4 视图 LRU,超限销毁最早者 |
| 旧用户升级后窗口行为变化 | 首次启动引导文案更新(岛双击呼出面板) |
