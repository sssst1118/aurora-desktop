# 截图功能设计

> 2026-08-18。用户提出:增加截图功能,完整的逻辑链。定位:日常主力工具的截图路径(替代微信/QQ 截图)。

## 需求定位与决策(用户已确认)

| 决策点 | 结论 |
|---|---|
| 选区交互 | **松开即截图**:拖完松开瞬间完成截图+复制+保存,最快路径;失败才提示 |
| 结果处理 | **复制到剪贴板 + 自动保存**到 `图片\Aurora 截图\截图_YYYYMMDD_HHMMSS.png` |
| 触发入口 | **仅全局热键**(默认 **Ctrl+Alt+A**,设置页可改,复用热键录制组件;AI 热键默认改为 Ctrl+Alt+E 让位——原 ctrl+alt+a 冲突,用户已确认) |

## 逻辑链

```
触发层 → 选区层 → 截图层 → 结果层
  热键      变暗+拖框   物理截图    复制+保存+提示
```

## ① 触发层

- 全局热键 `Ctrl+Alt+S`(与现有 Ctrl+Shift+Space / Ctrl+Alt+D / Ctrl+Alt+V / Ctrl+Shift+H 无冲突)
- 走现有 hotkey.rs 热键系统:AppConfig 加 `screenshot_hotkey` 字段 + apply_hotkeys 新条目,热键 diff 注册/注销天然生效
- 热键回调 → `screenshot_begin`:对每个显示器动态创建全屏遮罩窗口(label=`capture-{i}`),复用壁纸模块的多屏枚举(逻辑像素坐标化)

## ② 选区层(前端,新窗口 CaptureView.vue)

- 窗口:全屏、无边框、置顶、透明;前端渲染:半透明黑遮罩 + 十字光标 + 选区矩形 + 实时尺寸标注(如 `800×450`)
- 交互:`pointerdown` 起 → `pointermove` 更新 → `pointerup` 结束(松开即确认);`Esc` 或右键 → 取消(关窗回 IDLE)
- 选区 < 5px → 视为误触取消
- **坐标换算**:前端坐标是逻辑像素,`await getCurrentWindow().scaleFactor()` 取缩放 → 选区乘 scale 得物理像素,连同 monitor_index 传给后端(屏内相对坐标)
- 松开后:`window.hide()` 隐藏遮罩窗(防截进图)→ 100ms 后 invoke `screenshot_capture`

## ③ 截图层(Rust,commands/screenshot.rs,零新依赖)

- 命令 `screenshot_capture { monitor, x, y, w, h }`(物理像素,屏内相对)
- **整虚拟桌面一次 BitBlt**(GetDC(NULL) + CreateDIBSection 32bpp top-down + BitBlt SRCCOPY)→ 按 monitor rect(GetMonitorInfoW 物理坐标)定位该屏 → 按选区裁出行 → BGRA 像素
- **复制剪贴板**:OpenClipboard/EmptyClipboard/GlobalAlloc(BITMAPINFOHEADER 40B + 像素,biHeight 负=top-down)/SetClipboardData(CF_DIB)/CloseClipboard——CF_DIB 是 Windows 图片剪贴板标准格式,微信/画图/PowerPoint 均可粘贴
- **保存**:known-folders 的 Picture 目录 + `Aurora 截图` 子目录;文件名用 GetLocalTime(零新依赖)格式化 `截图_20260818_153012.png`;png crate 编码
- 失败分级:截图失败 → 整体错误;复制失败但保存成功 → 提示"已保存但复制失败"

## ④ 结果层

- invoke 返回 {path, w, h} → 前端 emit `screenshot-done` → 岛窗口监听显示 hint「已截图 800×450 · 已复制 · 已保存」
- 遮罩窗口销毁(每个截完即关)

## 状态机

```
IDLE --热键--> ARMED(遮罩窗打开,忽略重复热键)
ARMED --mousedown--> SELECTING
SELECTING --mouseup--> CAPTURING(隐藏窗→截屏→复制→保存→提示→关窗) --> IDLE
ARMED/SELECTING --Esc|右键--> 关窗 --> IDLE
CAPTURING --失败--> 错误提示(分级) --> IDLE
```

## 边界情况

| 场景 | 处理 |
|---|---|
| 多屏 | 每屏一个遮罩窗;选区在哪个屏就在哪个屏截;跨屏拖选=取松开时所在屏(MVP 限制单屏) |
| 125%/150% 缩放 | 前端 scaleFactor 换算逻辑→物理 |
| 选区 <5px | 误触取消 |
| 截图时按「全部显示/隐藏」 | 遮罩窗不在 win_utils LABELS 列表,天然不受影响 |
| 拔屏/截图失败 | 分级错误提示,回 IDLE |
| 热键连按 | ARMED/SELECTING 状态忽略 |
| 应用退出 | 遮罩窗随窗口管理清理 |

## 集成点

- 热键:hotkey.rs 加 `screenshot` 条目(带开关由热键存在性天然门控)
- 多屏:win_utils::logical_monitors(逻辑) + EnumDisplayMonitors(物理 rect)
- 剪贴板:windows-sys CF_DIB 自研(与项目"自研优于引库"一致)
- 依赖:零新增(windows-sys/png/known-folders 已有;windows-sys 补 `Win32_Graphics_Gdi` feature)
- 窗口:动态 WebviewWindowBuilder,App.vue 按 label 分流(与 wallpaper_ 前缀同模式)
